# Библиотека Stifler_relay

Библиотека для эффективного управления блоком из 4-х силовых реле (`end`, `pu`, `minus`, `plus`) с использованием ШИМ (PWM) на микроконтроллерах ESP32.

Основная особенность библиотеки — **аппаратное снижение энергопотребления и нагрева реле**. При включении любого реле на него подается максимальный ток для надежного замыкания контактов («кик»/форсаж), а через 100 мс библиотека автоматически переводит ШИМ в режим удержания с пониженным заполнением.

---

## Принцип работы (Форсированный режим / Kickstart)

Удержание катушки реле требует значительно меньше энергии, чем её первоначальное срабатывание. Библиотека использует этот физический принцип:

1. При вызове метода `.on()` выбранное реле подключается к аппаратному каналу ШИМ ESP32.
2. На катушку подается максимальный ШИМ-сигнал (`pwm_duty::max`, обычно 100% заполнения).
3. Запускается таймер `kick` на **100 мс**.
4. Метод `loop()`, который должен циклически вызываться в основном коде, отслеживает завершение таймера и программно снижает коэффициент заполнения ШИМ до экономичного уровня (`pwm_duty::relay`).

---

## Зависимости

Для работы библиотеки требуются следующие компоненты, которые должны быть определены в вашем проекте (например, в `<charger_general.h>`):

* **Аппаратные пины**: `pin::rl::end`, `pin::rl::pu`, `pin::rl::minus`, `pin::rl::plus`
* **Настройки ШИМ**:
* Название канала: `ch_pwm::rl`
* Частота: `pwm_freq`
* Разрешение: `res_pwm::relay`
* Заполнение форсажа: `pwm_duty::max`
* Заполнение удержания: `pwm_duty::relay`


* **Таймер**: Библиотека `GyverTimer` (класс `GTimer`).

---

## Структура классов и каналы управления

Библиотека предоставляет доступ к 4 независимым объектам реле внутри основного класса:

| Имя объекта | Описание |
| --- | --- |
| `end` | Реле завершения / конечного контура |
| `pu` | Реле пускового устройства / блока управления |
| `minus` | Реле минусовой шины |
| `plus` | Реле плюсовой шины |

Каждый из этих объектов имеет одинаковый интерфейс управления:

* `void on()` — включить реле (с форсированным импульсом).
* `void off()` — выключить реле.
* `bool state` — текущее состояние реле (`true` — включено, `false` — выключено).

## Пример использования

```cpp
#include <Arduino.h>
#include <stifler_relay.h>

// Создаем объект управления реле
Stifler_relay relays;

void setup() {
    Serial.begin(115200);
    
    // Инициализация ШИМ каналов для реле
    relays.begin();
    
    Serial.println("Инициализация реле выполнена.");
}

void loop() {
    // ОБЯЗАТЕЛЬНО: Вызываем loop для обработки таймеров удержания ШИМ
    relays.loop();

    // Пример логики работы (демонстрация)
    static uint32_t myTimer = millis();
    static bool step = false;

    if (millis() - myTimer > 5000) { // Каждые 5 секунд меняем состояние
        myTimer = millis();
        step = !step;

        if (step) {
            Serial.println("Включение реле PLUS и MINUS...");
            relays.plus.on();
            relays.minus.on();
        } else {
            Serial.println("Выключение реле PLUS и MINUS...");
            relays.plus.off();
            relays.minus.off();
        }
    }
}

```

---

## Важные замечания для разработчика

> ⚠️ **Критически важно:** Функция `relays.loop()` должна вызываться в основном цикле `void loop()` как можно чаще и без использования блокирующих задержек `delay()`. Если главный цикл будет заблокирован, реле останется в режиме максимального тока (`pwm_duty::max`), что приведет к их перегреву.
> ℹ️ Поскольку все реле делят между собой **один аппаратный ШИМ-канал** (`ch_pwm::rl`), одновременный вызов `.on()` для нескольких реле перезапустит таймер «кика» на 100 мс, что абсолютно безопасно и обеспечит надежное удержание для всех активных пинов.
